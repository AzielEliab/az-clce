# AZ-CLCE — iPhone & Android

Compare what something looks like, what was written, and what it actually does.

1. `cd mobile && flutter create --org com.azieeliab --project-name azclce .`
2. `flutter pub get`
3. `flutter run`, then press **Score**.

Four fields: What it looks like (R), What they wrote (D), What it actually does (P),
Missing pieces (N). Numbers, import, and export sit under **Advanced**.

Offline. No analytics. Light and dark follow the system. Gold focus.

Application id: `com.azieeliab.azclce`

## Open in Android Studio / Xcode

The `android/` and `ios/` folders here are skeleton READMEs because
this tree was written without the Flutter SDK on PATH.

```bash
cd mobile
flutter create --org com.azieeliab --project-name azclce .
flutter pub get
flutter run
```

Then open `android/` in Android Studio, or `ios/Runner.xcworkspace` in
Xcode.

## Honest scope

CLCE detects inconsistency, not intent. Type D is a label, not a finding
of malice. Human validation required. Not a cybersecurity exploit, not a
scanner of other people's systems, not a lie detector. Advisory scores
only.
