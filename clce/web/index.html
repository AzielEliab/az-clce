AZ-CLCE

Cross-Layer Consistency Engine. Inconsistency, not intent.

Score representation (R), description (D), and reality (P) as token sets. Jaccard triple, pairwise average, optional CLCE+ with missing elements (N). Type D is a label, not a finding of malice. Human validation required.

CLCE detects inconsistency, not intent. Type D is a label, not a finding of malice. Not a cybersecurity exploit, not a scanner of other people's systems, not a lie detector. Advisory scores only. Threshold 0.7 is the paper's acceptable line, not a pass/fail of truth. Loopback UI. Self-contained CSS. No telemetry.
